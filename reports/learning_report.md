## 附录 A：状态与原因码释义

| 状态 | 含义 |
|---|---|
| 答对（`correct`） | 有效答案且在有效期答案键下判定正确 |
| 答错（`wrong`） | 有效答案且可判定为错误——是真实的答错证据 |
| 未作答（`not_answered`） | 独立到场，但无提交或答案为空 |
| 未参加（`not_attended`） | 缺席、无该环节签到，或仅为协助参与 |
| 无法判断（`indeterminate`） | 有材料但映射/答案键/签到/重复提交等导致不能判断 |

| 原因码 | 中文说明 |
|---|---|
| `absent_record` | 签到表登记为缺席 |
| `no_attendance_record` | 查无该环节有效签到记录 |
| `assisted_participation` | 属于协助参与，不能作为独立掌握证据 |
| `blank_answer` | 答案为空，按未作答处理 |
| `no_response_row` | 没有该阶段的作答记录 |
| `no_measurement_mapping` | 题目在测量版本表中没有主题映射 |
| `mapping_out_of_window` | 作答日期不在题目映射有效期内，题目含义可能已变化 |
| `no_answer_key` | 缺少对应版本/有效期内的答案键，对错无法判定 |
| `duplicate_response` | 同一人同一题同一阶段存在多条作答，取值不确定 |
| `response_without_attendance` | 有作答但没有对应环节签到，参与范围无法确认 |
| `item_topic_differs_from_session` | 该题映射主题与当场课程主题不同，不能作为当场内容的掌握证据 |
| `pre_post_different_form_version` | 前测与后测来自不同量表版本，不能直接比较变化 |
| `household_answers_conflict` | 同一家庭出现互相冲突的共同作答，不能并作多份一致证据 |
| `household_proxy_questionnaire` | 问卷为家庭成员代填/合填，仅作家庭层面反馈 |
| `observation_missing` | 该活动没有可用的拓印观察记录 |
| `unknown_response_phase` | 作答阶段不是 pre/post，无法放入前后测设计 |
| `no_instrument_for_session` | 该场没有任何测量题目，学习变化无工具可测 |

## 附录 B：复用方式

1. 新一轮资料按 `data/manifest.json` 的列约定放入新目录（建议 `rounds/YYYY-roundN/`）。
2. 运行：`python3 -m assessment.cli --data <资料目录> --out reports/`。
3. 若课程主题映射被更正，保存旧版 `measurements.csv`，加 `--mapping-baseline <旧measurements.csv>`，报告第 8 节会指出受影响结论。
4. 阈值可用 `--min-pairs` 调整（默认 3；低于阈值只给谨慎建议）。
